## 📖 О проекте

**D&D AI Character Generator** — это интеллектуальная система, генерирующая уникальных и сбалансированных персонажей для настольной ролевой игры Dungeons & Dragons 5-й редакции. 

В отличие от классических методов (ручное распределение или бросок кубиков), система использует **гибридный подход**:
- 🧠 **Вариационный автокодировщик (VAE)** на базе PyTorch отвечает за креативность и разнообразие.
- 📐 **Правила D&D 5e** гарантируют валидность персонажа (бонусы расы, требования классов, расчёт КД и ХП).

### 🔍 Ключевые возможности

| Функция | Описание |
|---------|----------|
| **Генерация по параметрам** | Выберите расу и класс — получите готового персонажа со статами, модификаторами, КД и ХП. |
| **Соблюдение правил D&D** | Бонусы расы, минимальные требования класса, расчёт производных параметров. |
| **Сохранение результатов** | Все созданные персонажи автоматически сохраняются в CSV-файл `my_heroes.csv`. |
| **Интерактивный интерфейс** | Удобный командный интерфейс с выбором по номеру или названию. |
